# MyAgentGarden

Spontaneous Agent Ideas, Agent Knowledge & Technologies, and myAgentCreatures.

## Project Structure

```text
MyAgentGarden/
├── ideas/
│   ├── inbox/
│   ├── incubating/
│   └── README.md
├── knowledge/
│   ├── concepts/
│   ├── tools/
│   ├── patterns/
│   └── README.md
├── creatures/
│   ├── templates/
│   ├── active/
│   ├── retired/
│   └── README.md
└── README.md
```

## How to Use

- Capture raw thoughts in `ideas/inbox/`
- Move promising ideas into `ideas/incubating/`
- Record reusable knowledge in `knowledge/`
- Define and evolve agent creatures in `creatures/`
